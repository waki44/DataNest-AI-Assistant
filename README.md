# DataNest - Cyberpunk AI Desktop Operator ⚡

A futuristic standalone Windows AI desktop assistant and system monitoring dashboard built with **CustomTkinter** and powered by the **Gemini API**.

## Key Features
- **Cyberpunk Dark UI**: Glassmorphic neon theme designed with CustomTkinter.
- **Hardware Telemetry**: Live CPU, RAM, and Disk metrics with real-time analytics graphs.
- **Process Supervisor**: Real-time task manager tracking resource-heavy applications.
- **Conversational Intelligence**: Multi-turn chat assistant with contextual execution.
- **Voice Capabilities**: Speech recognition and text-to-speech engine.

## Quick Start
1. Clone the repository:
`ash
git clone [https://github.com/waki44/DataNest-AI-Assistant.git](https://github.com/waki44/DataNest-AI-Assistant.git)
cd DataNest-AI-Assistant
`

2. Install dependencies:
`ash
pip install -r requirements.txt
`

3. Configure your API Key:
Rename config.example.json to config.json and add your Gemini API key.

4. Launch the application:
`ash
python gui_assistant.py
`
